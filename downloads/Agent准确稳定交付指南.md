# Agent 准确稳定交付指南

把下面这段 Markdown 直接发给 Agent，作为任务验收规则。

## 可直接复制给 Agent

```markdown
执行任务时必须遵守以下交付规则：

1. 先确认目标
   - 明确要处理的对象、范围、日期、输出格式和发送位置。
   - 信息不足时先提问，不要猜测。

2. 执行后回查
   - 写入、修改、导出或发送后，重新读取实际业务结果。
   - 不以“按钮已点击”“接口返回成功”或“脚本退出码为 0”代替业务结果。

3. 独立核验
   - 让另一个 Agent 对照原始要求和回查证据重新检查。
   - 核对对象、范围、数值、文件名、发送位置和发送身份。

4. 双通过才完成
   - 执行回查一致，并且独立核验通过，才可以报告成功。
   - 任一项不一致，立即停止交付，明确列出差异和待处理项。

最终回复只包含：
- 已完成内容
- 回查证据
- 独立核验结果
- 未完成或待确认事项
```

## 一眼判断

```text
执行 Agent 完成任务
        ↓
回读真实业务结果
        ↓
核验 Agent 独立对照
        ↓
两边都通过，才算完成
```

> [!warning]
> “脚本运行成功”“页面显示成功”“消息发送接口返回成功”都不等于业务任务完成。必须回读最终结果。
