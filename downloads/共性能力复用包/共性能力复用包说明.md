# 共性能力复用包（脱敏示例）

把做成一次的任务交给 Agent 整理为可复用能力。

## 包含内容
- Skill 模板：触发条件、步骤、工具、异常处理、验收标准
- SOP 模板：输入、执行、输出、回读与失败处理
- 页面搭建模板：组件、交互、响应式与浏览器验收

## 使用方法
1. 把本包交给 Agent 阅读。
2. 让 Agent 根据你的任务补齐业务口径与工具依赖。
3. 安装新 Skill 前先做安全审查。
4. 用示例数据运行最小测试，回读真实结果后再投入业务。

## 脱敏门槛
禁止包含姓名、客户、员工、店铺、SKU、订单、财务数字、账号、Token、Cookie、密钥、内部链接、本机绝对路径及登录信息。真实数据一律换成示例假数据。
