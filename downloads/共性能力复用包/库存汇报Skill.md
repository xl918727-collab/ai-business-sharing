# 库存汇报 Skill（脱敏示例）

## 适用场景
从授权库存数据源读取多站点库存，生成日期化 Excel 与群内摘要。

## 输入
- 数据日期与站点范围
- 授权数据源或导出文件
- 库存口径与异常阈值

## 执行流程
1. 校验日期、站点和字段完整性。
2. 按平台隔离库存映射，禁止跨平台覆盖。
3. 计算库存、在途与异常清单。
4. 生成日期化 Excel 和精炼摘要。
5. Agent 回读文件名、记录数和目标群发送结果。

## 验收
来源可追溯；口径一致；文件名含日期；发送后可回读；缺失数据明确标注。

> 本示例已移除真实 SKU、店铺、账号、群 ID、财务数据和内部路径。
