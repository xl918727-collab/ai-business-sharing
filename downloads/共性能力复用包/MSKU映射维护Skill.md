# MSKU 映射维护 Skill（脱敏示例）

## 适用场景
按指定平台、店铺、完整 MSKU 与 SKU 维护映射，并即时回读启用状态与字段一致性。

## 通用执行流程
1. 锁定任务范围、数据日期与业务口径。
2. 只读取已授权数据，校验字段完整性与来源。
3. 按业务规则处理并保留可追溯明细。
4. 生成可使用的文件、看板或汇报。
5. 原 Agent 回读真实结果，必要时由另一 Agent 交叉核验。

## 验收
范围正确；公式与口径可复算；未知项明确标注；交付物可打开；结果经过回读。

> 本示例已移除真实人员、店铺、SKU、订单、财务数据、账号、密钥、内部链接与本机路径。
